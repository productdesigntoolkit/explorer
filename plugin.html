Das Product Design Toolkit als Plugin

85 Methoden, geführt statt nachgeschlagen. Das Plugin bringt den kompletten Product Design Toolkit in Claude Code: vom Business Model Canvas über Jobs to be Done bis zum Go-to-Market. Jede Methode endet mit einem Ergebnis als Datei, nicht mit einem Gespräch.

Plugin herunterladen Quellcode auf GitHub

Installation

ZIP entpacken

Das heruntergeladene Archiv an einen festen Ort entpacken, zum Beispiel ins Benutzerverzeichnis.

unzip pdt-claude-plugin-0.1.0.zip -d ~

Als lokalen Marketplace anmelden

Claude Code erfährt damit, wo das Plugin liegt. Es wird keine Verbindung nach aussen benötigt.

claude plugin marketplace add ~/pdt-claude-plugin

Installieren

Danach stehen alle Befehle in jeder Sitzung zur Verfügung.

claude plugin install pdt@pdt

Kontrolle mit claude plugin details pdt. Die Ausgabe listet 93 Komponenten und 11 Agents.

Verwendung

Wer die Methode kennt, ruft sie direkt auf:

/pdt:lean-canvas /pdt:problem-statement /pdt:product-market-fit

Wer noch sucht, beschreibt die Lage in eigenen Worten. Der Method Finder meldet sich ohne Befehl und verweist auf die passende Methode. Für einen Einstieg ohne Vorgabe genügt /pdt:start.

> Wir haben eine Idee, aber ich weiss nicht, ob das Problem echt ist. Fang beim Problem an, nicht beim Produkt. Für die strukturierte Variante: /pdt:problem-statement und /pdt:user-interviews

Jede Methode führt durch ihre Felder, verlangt Belege statt Behauptungen und schreibt das Ergebnis nach pdt-workspace/ im aktuellen Projekt.

Gut zu wissen

Das Plugin belegt rund 9000 Token in jeder Sitzung, weil alle Methoden ohne Nachladen bereitstehen. Wer an anderem arbeitet, schaltet es mit claude plugin disable pdt@pdt ab und später wieder an.
